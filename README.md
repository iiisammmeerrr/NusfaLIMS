# Nusfa LIMS — Vite + React UI Prototype

A dark-first, responsive Diagnostic Pathology LIMS frontend prototype.

## Run
```bash
npm install
npm run dev
```

## Included
- Dashboard with KPI cards, charts, pipeline and activity
- Patient registry
- Test management
- Package management
- Sample tracking
- Result entry & verification
- Find Reports + QR actions
- Billing
- Referral management
- Analytics
- Lab Setup / Report Format / Billing Format / Users & Roles / Settings placeholders
- Dark-first theme + Light mode toggle
- Responsive mobile/tablet layout
- Reusable components and mock data
- Quick-action modal and toast interactions

## Important
This is a frontend prototype. It uses mock/local UI data only. Authentication, real database, backend APIs, PDF generation, secure report tokens, QR verification, file storage, audit logging and production permissions should be connected before production deployment.
